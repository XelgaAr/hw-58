# Результаты проверки

Проверка: 8 ноября 2026 года. Runtime: Node.js v22.16.0. Workflow настроен на Node.js 24.

## Выполнено

`npm run test:native`: **79 passed, 0 failed, 0 skipped**. Это самостоятельные проверки `node:test`, не переименованный запуск Vitest.

Проверены известные SHA-256 и PBKDF2-векторы, параметры по умолчанию и явные параметры, Unicode, неправильные типы, некорректные параметры и хеши, верный/неверный пароль, случайные соли и совпадение Web Crypto с node:crypto. Web Crypto в этих нативных тестах выполнялся в Node.js. Также проверена раздача собранного сайта под /repository-check/.

Скриншот реального вывода: [tests-native.png](tests-native.png). Текст: [tests-native.txt](tests-native.txt).

Сборка `npm run build` и проверка синтаксиса/JSON `node scripts/check.mjs` завершились успешно. CLI дополнительно проверен через `npm start`.

HTML/CSS визуально проверены в Chromium при ширине 1440 и 390 px; горизонтального переполнения нет. Разметка и стили переданы в DOM браузера напрямую; интерактивный код на этих визуальных снимках не запускался.

## Не подтверждено в этой среде

`npm install` не завершился: DNS-ошибка `EAI_AGAIN` для `registry.npmjs.org`. Поэтому **8 исходных Vitest-тестов** и покрытие Vitest здесь не запускались. Исходные тестовые файлы сохранены побайтно.

Chromium блокирует переходы к localhost и файловым адресам с `ERR_BLOCKED_BY_ADMINISTRATOR`. Подготовлен воспроизводимый `npm run test:browser`, но полный навигационный браузерный прогон здесь не подтверждён. Визуальная/DOM-проверка не выдаётся за этот прогон. Скриншоты Vitest не подставлялись вместо реальных результатов: `npm run test:report` создаёт их после настоящего запуска.

Репозиторий и опубликованный Pages-сайт не создавались. Для проверки публикации необходимо выполнить workflow в собственном репозитории.
